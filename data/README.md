# Dataset

This project uses the Online Retail II dataset from the UCI Machine Learning Repository.

## Source

UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/502/online+retail+ii

## Dataset Periods

The dataset contains two sheets:

- Year 2009-2010
- Year 2010-2011

The original Excel dataset is not stored in this repository. Download the dataset from the source above and place it in the local project folder before running the notebook.
